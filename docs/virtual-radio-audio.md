# Virtual radio and audio monitor

Device label: SignalCluster Virtual Radio Receiver (SC-VRR-01). The receiver is software simulation only; it does not control physical SDR hardware, ingest live RF, or transmit radio signals.

The browser UI generates synthetic pulsar-like pulses, calibration tones, noise, and AM-style audio and can export generated samples to mono 16-bit PCM WAV. This is not a real pulsar recording or a direct rendering of an RF carrier.
